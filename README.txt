PARCEL PORT — SHAPE WORKSHOP FOR KIRANI

Open index.html or upload ALL files in this folder to GitHub Pages.
No install or build is needed. Keep assets/ beside index.html.
English / Bahasa Indonesia. English opens by default. Indonesian remains available. Existing visitors switch to English once with this revision; later language choices are remembered.

30 small steps across six docks. Surface area receives three docks of foundations and practice; volume follows; an eight-step compound-shapes section follows; short word problems finish the trail.
Suggested lesson: start docks 1–3. Move to volume or deliveries only when ready. The full trail may span several lessons. Time estimates are flexible, not timers.

Student tools: selectable net faces, countable unit squares, add/remove cube layers, number input, clues, worked examples, read aloud (depends on device voices), notes, break screen, reminder card.
Teacher: local progress distinguishes first-try/no-hint, supported, and example-used completion. A correct answer is not a validated mastery assessment. Export CSV includes working notes. Revisit supported questions with the retry button; retry replaces that item's current result.

Progress is saved only in the current browser, under a new workshop key; original-site progress is separate. It does not sync between devices. Moving to a different hosted domain will not move progress. Private browsing can limit storage.

Core pages, scripts and harbour art work offline after extraction. Google Fonts are optional and fall back to system fonts offline.
No tracking, accounts, scores, countdowns, or external submissions. Teacher notes are not password protected.

Scope: cube/cuboid foundations, opposite faces, area units, closed and open-top surface area, layers/volume, one inverse-volume question, joined-block volume and surface area (including both hidden contact patches), strategy selection and reasoning. This is focused reinforcement for TKA preparation, not a complete official TKA syllabus or exam simulation.
